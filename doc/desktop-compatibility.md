# 桌面客户端兼容检查

助手版本：0.4.6。

## Codex 26.908

Codex `26.908.40834`（Windows 安装版本 `26.908.4834.0`）改用独立应用工具管道，旧助手仅在 Codex 子进程命令行中寻找旧入口，因此会显示“未检测到客户端工具连接”。0.4.6 保留旧入口候选，并枚举本机相同协议前缀的命名管道；先通过 Windows API 核对管道服务器 PID 与当前用户的 Codex 主进程一致，再以有限时间、有限帧大小读取 `tools/list`，确认属于 `codex_app`。不依赖从 Codex 启动助手，不读取账号密钥，不连接其他进程的工具服务。

同时适配任务设置协议 v2，保留 v1。模型和计划模式仍只影响后续消息，不修改正在执行的任务权限；新版必须返回 `applied: true` 才视为已接受，拒绝或未知响应不能显示为成功。

本机只读验证已清除继承的工具管道环境变量，确认新发现机制仍能连接，客户端状态无兼容限制，可读取 30 条任务摘要和 11 个项目。没有为验收重启 Codex、发送消息、停止任务或切换真实任务设置；设置变更的拒绝、确认和版本分支由隔离自动测试验证。

安装 `ChatGPT-Remote-Assistant-Setup-0.4.6.exe` 覆盖旧助手后，在主界面确认“助手 v0.4.6”“服务器已连接”及 Codex“就绪”，再刷新手机网页。无需更新服务器。

## 检查策略

- 不再要求 Windows 安装包版本等于单个常量。应用版本、安装包版本是不同编号：应用 `26.903.61454` 对应安装包 `26.903.8094.0`；旧应用 `26.901.51231` 对应 `26.901.6511.0`。
- 原生发现过程只查找当前 Windows 用户和会话的 Codex 进程，返回其实际安装路径。未运行、未识别和接口变化分别提示，不再都显示“版本未经验证”。
- 只读解析该安装目录的 `app.asar` 元数据和版本化 IPC 定义，使用 ASAR 库及 JavaScript 解析器，不执行、修改或复制分发原客户端代码。读取量受限，按文件路径、大小和修改时间缓存。
- 核对会话流、跟随和所有者发现协议；核心读取协议不匹配或定义无法确认时拒绝进入。只读校验原 SQLite 索引字段，不迁移或写入原数据库。
- 验证 IPC 初始化响应、工具连接，以及存在任务时的只读项目查询。缓存检查结果十秒，连接中断后重新检查。
- 发送、停止、调整方向、模型设置与审批分别按已实现的协议版本开放。不匹配的功能在网页禁用，并在助手端再次阻止执行；不会通过试发消息或试停任务探测兼容性。
- 不明确的 IPC 成功格式作为“结果未确认”处理，不自动重发；新建任务响应也必须含有效任务 ID，避免把未知格式当作成功。

## 已读状态变化

`26.903.61454` 将 `thread-read-state-changed` 从 v2 升为 v3，增加了由桌面端提供的身份上下文。本助手不构造该身份上下文、不读取账号秘密来模拟它，也不将旧载荷改标为 v3 发送。

手机端仍可清除自身的完成未读标记。v2 客户端继续同步原桌面已读广播；v3 客户端的桌面未读标记由桌面自身处理，可能需要在电脑上查看后才清除。

## 升级与验证

- 使用完整的 `ChatGPT-Remote-Assistant-Setup-0.4.3.exe` 覆盖升级。先从托盘退出旧助手，不需要关闭 Codex 或停止其任务；保留设备 ID、密码、授权和订阅。0.4.3 增加的计划确认与模式切换见[计划模式](./plan-mode.md)。
- 已只读检查本机两份真实安装包，上述两个应用版本的核心会话、发送、停止、模型设置及审批协议均匹配。
- 当前运行中的旧客户端通过初始化、索引、项目及任务摘要只读检查。没有为测试强制升级或重启正在运行的 Codex。
- 新版应用的安装文件检查不等于另一台电脑的完整实机验收。新电脑安装助手后还需实际确认连接、消息发送及审批；本次不宣称已在那台电脑执行过真实任务。
- 后续小版本在协议不变且检查通过时无需更新助手；协议、索引或工具返回结构有破坏性变化时仍需适配，不能保证未来所有版本自动兼容。

2026-09-10 验证：类型检查、生产构建、原生编译通过；216 项单元/集成测试、68 项 Chromium 测试和 30 项 WebKit 测试通过。Windows 布局覆盖十种状态，包括部分兼容和完全阻断时的版本、原因提示。

完整包使用自带 Node 和依赖，在隔离的助手数据目录和测试服务器中完成启动，远控保持关闭，真实旧客户端只读检查通过。未向真实任务发送消息、停止、修改模型或答复审批。当前 Windows 用户已有安装，因此未运行会注册/卸载该现有产品的安装器回归脚本。

安装包仍未签名。生产依赖审计仅剩原有 `urllib` 高危重定向公告，本次新增解析依赖未引入新的生产公告；既有支付相关放行限制继续有效。
