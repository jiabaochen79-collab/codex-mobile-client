ChatGPT 远程助手

这是独立的非官方连接工具。需要在电脑上安装并运行受支持的 Codex 桌面客户端，模型账号和 API 费用由原配置承担。

安装会放置完整程序、创建开始菜单入口，并可选择创建桌面快捷方式。Node 运行时已经随安装包提供，不需要用户另外安装 Node.js。

安装不会自动开启远控、修改模型设置或调整 Windows 电源设置。电脑睡眠、休眠、关机或断电时，手机将无法连接；助手会显示检测到的电源配置风险。

如果检测到助手正在运行，点击安装器“确定”会自动退出助手并继续安装；无需关闭 Codex 或停止正在执行的任务。点击“取消”则退出安装。

卸载默认保留设备 ID、自定义密码、订阅绑定和历史附件。程序目录与用户数据目录分开，重新安装后可继续使用原配置。

本程序当前未进行代码签名，不代表由 OpenAI 或 Microsoft 发布、认证或担保。
