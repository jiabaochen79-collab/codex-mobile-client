# 0.4.53 纯手写提问卡片兼容性修复

日期：2026-10-12。

## 问题与修复

0.4.52 原生卡片定位逐字比较问题原文与桌面控件文字。但桌面显示会去掉 Markdown 格式，整理换行和多余空格，导致带格式的问题无法定位。纯手写问题还使用不同的输入框布局，原来的三层父节点查找范围不足。

本版本将普通 Markdown 问题转换为显示文字，并在原生层统一空白和实体文字比较。定位支持较深的纯手写卡片，查找止于当前任务文档；仍拒绝多输入框、多提交按钮或任务标题、进程身份不一致的情况。提交后也只核对目标任务中的未回答卡片。

窗口不可用、定位失败、输入框不支持填写、已有不同草稿和提交按钮不可用分别返回具体提示。读取输入框失败不再误报草稿冲突。原问题标识和正文的提交后验证、授权复核及结果不确定时不重发的规则保留。

本次不修改服务器实现、手机界面、通信协议、支付或订阅。服务器交付只需发布新版 Windows 安装包。
