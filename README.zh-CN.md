# ChatGPT 远程助手 · Codex Mobile

**电脑继续工作，手机随时接着处理。**

[English](README.md) | 简体中文

**[下载 Windows 版 · GitHub](https://github.com/jiabaochen79-collab/codex-mobile-client/releases/latest)** · **[Gitee 下载](https://gitee.com/gitee-is-future/codex-mobile-client/releases)** · [打开手机网页](https://remote.chatgptvip.asia/)

在手机上继续电脑里的 Codex 会话：查看进度、追加需求、处理提问与审批。无需搬动项目，也不必一直守在电脑前。

## 主要功能

| 功能 | 你可以 |
| --- | --- |
| 继续原有会话 | 查看执行过程和结果，随时追加需求、调整方向 |
| 电脑端任务排队 | 需求确认保存到电脑后，关闭手机网页也能继续执行 |
| 计划与目标模式 | 先确认方案再实施，或围绕目标持续推进 |
| 提问与审批 | 选择选项或自由输入回答，按任务调整权限 |
| 照片与文件 | 拍照、上传文件，支持 HEIC 照片处理 |
| 多电脑与多终端 | 切换已配对电脑，已授权终端无需接管即可操作 |
| 任务提醒 | 完成、异常或等待你决定时收到提醒，点击回到对应任务 |
| 更新与恢复 | 后台下载新版，手动确认安装；支持异常恢复 |

## 三步开始

1. **电脑安装助手**，打开并登录 Codex，确认就绪后开启「允许远程连接」。
2. **复制连接信息到手机**，在手机网页填写设备 ID 和连接密码。
3. **选择会话，开始使用**。任务仍在电脑执行，手机和电脑无需处于同一 Wi-Fi。

需要 Windows 10（19041+）/11 x64 和可用的 Codex 桌面客户端；电脑需保持联网、唤醒，Codex 与助手保持运行。

iPhone 通知需先「添加到主屏幕」，再从主屏幕打开并开启提醒；Android Chrome 可直接授权通知。
