# ChatGPT 远程助手 · Codex Mobile

**电脑继续执行，手机随时接着处理。**

[English](README.md) | 简体中文

[下载 Windows 助手](https://github.com/jiabaochen79-collab/codex-mobile-client/releases/latest) · [打开手机网页](https://remote.chatgptvip.asia/) · [反馈问题](https://github.com/jiabaochen79-collab/codex-mobile-client/issues)

Codex Mobile 将手机连接到 Windows 电脑上的 Codex 桌面任务。无需搬动工作区或把文件迁入云电脑，就能查看结果、追加需求、回答提问和审批，并在多台电脑之间切换。

> 本项目为独立的非官方软件，与 OpenAI 无隶属关系，也未获得其背书。使用前需要正常运行的 Codex 桌面客户端及自己的账号、模型使用权限；不包含 ChatGPT 会员、模型额度或云电脑。连接服务独立运营，服务端源码不在本仓库内。

## 可以做什么

| 功能 | 使用场景 |
| --- | --- |
| 查看会话和进度 | 手机查看任务与结论，按需展开命令细节，继续原有对话。 |
| 排队与调整方向 | 电脑忙碌时先提交后续需求，也可调整当前执行方向。 |
| 计划与目标模式 | 先审阅计划再实施，或向兼容的 Codex 提交目标及完成标准。 |
| 回答提问与设置权限 | 选择答案或输入自己的回复，调整当前任务的权限。 |
| 照片和文件 | 选择照片、拍照、上传文件，处理受支持的 HEIC 照片。 |
| 多电脑切换 | 分别配对电脑、自定义名称，在已授权设备间切换。 |
| 任务完成提醒 | 通过站内提醒和受支持的 Web Push 返回对应任务。 |
| 更新与恢复 | 后台下载更新，在支持的场景恢复异常退出的 Codex，不自动重发结果不明的任务。 |

## 快速上手

### 1. 准备电脑

1. 打开 Codex 桌面客户端并登录，确认能在电脑上正常打开、执行任务。
2. 使用 Windows 安装包安装并启动「ChatGPT 远程助手」。
3. 检查显示「服务器已连接」、「Codex 客户端 → 就绪」，并打开「允许远程连接」。
4. 点击「复制连接信息」，通过私密方式发送给自己的手机，内容包括手机网页地址、九位设备 ID 和连接密码。

「打开手机网页」是在当前电脑打开网页；给手机配对时，通常优先使用「复制连接信息」。不要把连接信息发到公开截图、Issue 或群聊中。

### 2. 连接手机

1. 在手机浏览器打开助手复制出的地址。运营服务地址为 [remote.chatgptvip.asia](https://remote.chatgptvip.asia/)。
2. 填写电脑的「设备 ID」及当前的「验证码或自定义密码」。设备 ID 为九位数字；自动验证码为八位字符；自定义密码为 8～64 位。可点击眼睛图标核对输入。
3. 在自己的设备上，可勾选「记住此设备（30 天免登录）」，然后点击「连接」。记住的授权仍可能被撤销或提前失效。
4. 在「项目与会话」选择已有任务，或点击「+」创建任务。如果服务要求激活，先打开「订阅与权益」。

<img src="doc/screenshots/mobile-connect.png" alt="手机连接表单：演示设备 ID 和隐藏的演示密码" width="312">

自动换码模式下，每次成功连接后验证码都会变化。已经授权的手机可以继续使用原授权；新手机配对时要使用电脑显示的当前验证码。需要固定密码时，在 Windows 助手点击密码设置图标；「撤销全部授权」会断开现有手机授权。

### 3. 发送第一个任务

核对当前电脑和会话，输入需求，点击向上箭头发送。可以在手机查看结果，也可以稍后返回。实际任务在电脑执行；电脑睡眠或退出 Codex 会中断其执行环境。

<img src="doc/screenshots/mobile-chat.png" alt="手机会话：用户需求、折叠的执行过程、清晰的结论和底部输入框" width="312">

## 常用操作

### 排队发送与调整方向

- 任务正在执行时，可以输入后续需求并「排队发送」。「待发送」区域展示电脑助手保存的队列。
- **看到「电脑已保存，排队中」后再关闭浏览器。** 已确认保存的队列由电脑继续处理，不依赖手机网页保持打开。草稿、正在上传的附件、提交结果不明的消息，都不等于任务已经保存。
- 展开发送按钮旁的选项，选择「调整方向」，可以修改当前执行方向；带附件的内容使用排队发送。
- 「停止当前生成」针对当前生成，和取消排队消息、暂停目标是不同操作。
- 如果显示「结果待核对」，请先检查上一条消息是否已经执行，再决定是否重试，避免重复提交。

更多说明：[排队与调整方向](doc/queued-send-and-steering.md)。

### 计划、目标、提问和权限

| 入口 | 用法 |
| --- | --- |
| **+ → 计划模式** | 先讨论方案，在计划生成后确认是否实施；输入框中会显示计划标记。 |
| **+ → 目标模式** | 输入目标及完成标准，再主动发送。兼容的 Codex 负责原生目标续行，仅选择模式不会开始执行。 |
| **提问卡片** | 选择合适的选项，也可以输入自己的回答，再提交卡片。 |
| **模型旁的盾牌图标** | 打开当前任务的「任务权限」，「…」菜单也提供同一入口。 |
| **… → 在线终端** | 查看已连接终端，其他终端正在控制时可主动接管；仅查看会话不需要抢占控制权。 |

按任务需要选择权限。「完全访问权限」授予较广泛的电脑访问能力，需要二次确认；普通使用不要求一律选择完全访问。模式及权限是否可用，以 Codex 和助手的实际兼容能力为准。

更多说明：[计划模式](doc/plan-mode.md) · [目标模式](doc/goal-mode.md)。

### 照片与文件

点击输入框旁的「+」，选择「照片图库」、「拍照」或「文件」。检查预览，等待上传成功后再发送。受支持的 HEIC 照片按照片流程处理；转换失败时保留原文件，并通过问题反馈说明情况。

当前服务在「订阅与权益」中展示的限制为：单次最多五个附件，每个不超过 25 MB，合计不超过 50 MB。同时受浏览器支持、电脑剩余空间和服务限制影响。关闭浏览器不会让尚未完成的上传自动继续。

### 添加与切换电脑

点击会话标题下方的电脑名称，或项目列表中的「切换电脑」，打开「我的电脑」。点击「+」配对另一台电脑；电脑旁的「…」可以重命名、调整顺序或移除当前浏览器对它的授权。

<img src="doc/screenshots/mobile-computers.png" alt="我的电脑弹窗：两台演示电脑、在线状态、添加及管理入口" width="312">

发送前核对电脑名称。每台电脑的任务、授权、服务权益和提醒设置分别保存；配对第二台电脑不会自动转移第一台电脑的订阅。

### 开启任务完成提醒

打开「… → 任务完成提醒」，为当前电脑开启提醒，选择任务完成和／或失败、中断提醒，并在提示时允许系统通知。若出现「开启系统通知」，点击它可为当前浏览器或 Web App 注册后台推送。

| 手机或浏览器 | 开启方法 |
| --- | --- |
| **iPhone／iPad，包含 Chrome** | 使用当前浏览器的「分享 → 更多（如需）→ 添加到主屏幕」。从主屏幕打开这个 Web App，按需重新连接，再在其中开启提醒。不需要转移到 Safari；本客户端不允许在普通 iOS 浏览器标签页开启后台推送。 |
| **Android Chrome** | 可直接在浏览器开启提醒并允许通知，不强制添加主屏幕应用。系统省电、通知设置、强制停止浏览器及网络状态可能影响送达。 |
| **桌面 Chrome／Edge** | 浏览器授权后支持 Web Push；Windows 助手本身不弹任务提醒。 |

<img src="doc/screenshots/mobile-notifications.png" alt="任务完成提醒：完成与异常提醒选项，以及能区分任务名称的最近提醒列表" width="312">

添加多台电脑后，需要分别开启提醒。点击站内提醒或系统通知可查看对应任务，不会自动发消息、批准操作或接管控制权。站内记录保留 30 天；系统通知只含状态和时间，登录后的列表会读取任务名称。送达仍取决于系统与推送服务，不支持时可继续使用站内列表。

### 试用、授权与问题反馈

- 在 Windows 或手机项目列表打开「订阅与权益」，查看当前电脑的服务状态。
- 有七天试用资格时，阅读并同意条款后主动领取。安装助手本身不会消耗试用时间，资格和到期时间由服务端确认。
- 使用授权码时，将其粘贴到「授权码」，同意条款后点击「激活授权」。开放在线购买时，可选择可用套餐并按页面完成支付；价格和条款以该页面为准。
- 服务到期不会停止电脑已经执行中的 Codex 任务，但新增远程操作可能受限。
- 手机打开「… → 问题反馈」，电脑点击「问题反馈」。提供复现步骤、发生时间和错误码，可选附上检查过的截图，在「我的反馈」跟进回复；也可提交脱敏的 [GitHub Issue](https://github.com/jiabaochen79-collab/codex-mobile-client/issues)。

## 更新与异常恢复

自动下载启用时，助手可在后台下载新版安装包；就绪后由你在更新对话框确认安装，也可以主动「检查更新」。升级保留设备身份、密码、记住的授权和用户数据；更新替换助手及其连接，不会主动结束 Codex 或正在执行的桌面任务。请等待连接恢复。

旧更新器可能需要手动覆盖升级一次，建议直接安装当前版本 `.exe`。更新器在电脑本地备份程序用于失败恢复，不再从服务器下载旧版安装包，详见[安装与电源设置](doc/windows-installer-and-power.md)。

Codex 未就绪时，先查看具体原因，再按需使用「客户端恢复」。恢复不会自动重发已中断任务或结果不明的消息，详见[异常恢复说明](doc/client-recovery.md)。

## 常见问题

| 情况 | 建议检查 |
| --- | --- |
| 连接按钮不可点击 | 填满九位设备 ID 和 8～64 位密码；确认是当前验证码，检查空格，必要时点击眼睛核对。 |
| 电脑离线 | 电脑保持唤醒、助手运行且远程连接已开启；两端能访问 HTTPS 服务，公司网络策略或 VPN 可能影响连接。 |
| Codex「未就绪」或兼容性提示 | 在电脑打开 Codex 并登录，确认本地任务可用；查看具体原因、升级助手，并检查「客户端恢复」。不能只凭版本号判断兼容性。 |
| 能查看，不能发送 | 检查查看模式、其他终端的控制权、服务到期情况，以及页面给出的兼容或权限原因。 |
| iPhone 没有提醒 | 从主屏幕打开 Web App，在其中为正确电脑开启提醒，并检查 iOS 通知权限。 |
| 第二台电脑没有提醒 | 提醒按电脑设置，需单独开启，并确认其助手在线、版本较新。 |
| 上传或发送停住 | 等待明确结果，恢复网络后重试，检查「待发送」；上一条结果不明时不要反复提交。 |
| 找不到较早消息 | 向上滚动，出现历史加载入口时继续加载；当前显示的一页不一定是整个会话。 |
| Windows 提示安装包风险 | 核对官方发布页和 SHA-256，当前安装包未签名。不要为了连接而关闭证书校验或系统防护。 |

## 隐私和开源边界

- 本仓库包含 Windows 助手、原生组件、手机网页、客户端测试、打包脚本和通信协议快照。
- 不包含连接服务器、管理后台、支付实现、部署文件、生产数据、凭据、证书或私钥，不提供完整的服务端自部署方案。
- 有效证书下的 HTTPS 保护传输。**这不是端到端加密：** 独立运营的服务器可以处理转发的任务内容及通知元数据。
- 设备 ID 和连接密码可能用于授权远程访问；遗失或不可信的授权应及时撤销。
- 问题反馈默认不自动附带聊天正文、任务文件和完整日志，提交前检查截图及诊断内容。不要在公开 Issue 提供密码、Cookie、TOTP 种子、模型密钥、私人文档或生产日志。
- 本文截图均为演示数据，安全问题请按 [SECURITY.md](SECURITY.md) 报告。

## 从源码构建

普通用户使用安装包即可。开发需要 Windows x64、Node.js 22.13 或更新版本、.NET Framework 4.8／原生构建工具；制作安装包还需要 Inno Setup。

```powershell
git clone git@github.com:jiabaochen79-collab/codex-mobile-client.git
cd codex-mobile-client
npm ci
npm run audit:public
npm run check
npm run native
npm run build
npm test

$env:RELAY_URL = 'https://remote.example.com'
npm run package:windows
npm run installer:windows
```

`RELAY_URL` 需指向兼容且独立运营的服务，示例地址不能用于实际连接。产物包含 `dist/agent.mjs`、手机网页及 `dist/client-web-manifest.json`；独立服务端可以校验并导入网页产物。协议快照说明见 [CONTRACTS.md](CONTRACTS.md)。
