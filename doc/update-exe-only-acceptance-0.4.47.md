# 0.4.47 EXE 单文件发布与更新验收

日期：2026-10-08。此版本移除独立发布签名及签名清单文件要求，保留 HTTPS、大小、SHA-256、允许下载路径、版本回放检查和本机程序恢复。

## 发布与升级

1. 先部署配套服务器和后台版本。
2. 后台“版本发布”只选择 Windows 安装包 EXE，点击“开始上传并校验”。服务器读取安装器内嵌版本并分配发布序号。
3. 安装包通过校验后，填写更新说明，选择指定设备试发或正式发布。历史发布记录和安装统计继续保留。
4. 0.4.46 及更早版本仍执行旧签名校验，必须手动运行一次 0.4.47 安装包覆盖升级。后续后台发布只需上传新版 EXE，不上传 JSON、SHA-256 文件或旧版安装包。
5. 助手自动下载新版包，用户确认安装；失败时从已验证的本机程序备份恢复，用户数据不回滚。

更新信任依赖 HTTPS、服务器及管理员权限。SHA-256 用于完整性检查，不提供独立发布者认证。安装包没有 Windows Authenticode 代码签名。
