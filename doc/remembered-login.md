# 手机记住设备与免登录

新版浏览器设备目录和多电脑切换规则见[多电脑切换](./multiple-computers.md)。以下单设备 Cookie 描述保留用于旧客户端兼容；新版以浏览器目录关联每台电脑的独立授权，当前页面通过明确的目标设备访问服务。

## 行为

- “用户名”沿用设备 ID，不增加账号中心。默认勾选“记住此设备（30 天免登录）”。
- 正确密码首次配对后，设备 ID 自动回填；免登录固定有效 30 天。浏览器关闭再打开、电脑助手或服务器正常重启不再要求输入密码。
- 未勾选沿用 24 小时临时授权，设备 ID 不保存，助手或服务器重启后需重新配对。
- 自动验证码成功配对后换码，不影响已授权手机。密码管理器使用标准 `username` / `current-password` 字段，可由用户另行保存固定密码。
- 手机“退出登录”撤销当前浏览器 Cookie 的所有标签页授权，保留设备 ID 回填，不影响其他浏览器和正在运行的电脑任务。取消勾选会删除设备 ID 的本地记忆。
- 改密码、切换密码模式、撤销全部授权、关闭远控均立即撤销全部手机授权。离线操作在助手重连时同步，不能靠重启恢复旧授权。
- 无痕模式、清理站点数据、换浏览器或访问地址可能丢失登录；30 天到期后需用当前密码配对。

## 实现与安全边界

- 浏览器 localStorage 只存设备 ID 与勾选偏好，不存密码、Cookie 或聊天正文。存储被禁用时仍可连接。
- 32 字节随机登录令牌只放在 `Secure; HttpOnly; SameSite=Strict; Path=/` Cookie 中；仅本地 HTTP 测试使用非 Secure Cookie。
- 服务器 SQLite `browser_sessions` 仅持久化免登录令牌的 SHA-256、随机授权 ID、设备 ID、服务器到期时间；未勾选会话不落盘。
- 电脑 SQLite `remembered_grants` 按服务器地址保存已批准的随机授权 ID 和到期时间，不保存手机 Cookie。修改密码与清除持久授权在同一事务内提交。
- 助手状态报告携带最多 32 个有效授权 ID。服务器在启用命令转发前以此核对自身会话，删除助手已撤销或遗失的授权；状态不会创建新的授权。旧助手进程更换时仍撤销旧授权，不错误宣称支持免登录。
- HTTP、WebSocket、附件、控制权继续共用原权限检查。服务器时钟负责最终到期，改电脑时间不能延长服务器授权；订阅与购买授权独立，三在线终端和单控制端规则不变。
- 先更新服务器与网页，再更新助手到 0.2.1。旧助手可取消免登录后临时配对；已有 24 小时 Cookie 不自动升级，用户需重新勾选配对一次。
- 备份数据库应受保护，回滚备份可能还原旧授权记录；恢复备份后必须撤销授权再开放服务。服务仍是可信转发，不是端到端加密。

## 验证入口

- `tests/integration.test.ts`：30 天 Cookie、仅哈希落盘、自动换码、两端重启、临时授权、独立退出、离线改密码/撤权/关闭远控、到期、重复登录替换及设备隔离。
- `tests/mobile-remember.spec.ts`：真实浏览器进程关闭再打开、无需重复配对、退出与 ID 回填、不勾选、改密码、存储禁用、320/390/1280 宽度截图。
- 完整原有回归仍覆盖项目、会话、图片/文件、模型、订阅以及控制权。浏览器自动化不等于 iPhone/Android 蜂窝网络真机验证。
