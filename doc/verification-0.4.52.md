# 0.4.52 手机回答与桌面提问卡片同步

日期：2026-10-11。

## 问题与修复

旧实现通过 steering 或 start-turn 发送提问回答，模型能够收到答案，但没有执行桌面卡片的提交回调。特别是提问所在轮次已经完成时，新轮次中的回答不会更新原卡片的本地状态。

本版本通过 Windows 原生无障碍控件提交对应的提问卡片。核对进程路径、启动时间、Windows 用户和会话、任务标题及问题文字后填写回答；保留不同于本次回答的桌面草稿。同一批次的问题整批显示在手机上，按原生卡片的下一步流程填写，最后仅发送一次。

提交前重新核对远控授权及提问状态；提交后核对卡片关闭及桌面历史中的原问题标识、问题文字和答案。结果不确定时返回未确认状态，不通过另一通道重发。旧式阻塞提问沿用原有回复接口。

未修改手机执行、订阅、支付、通信契约及服务器实现。服务器本次交付仅发布 Windows 更新包。

## 验证

- 独立真实任务验证完成后回答：原生卡片关闭，模型确认 Test A，答案进入正确任务。
- 独立真实任务验证运行中回答：卡片关闭，模型确认 Test A，历史中该答案仅一次。
- 独立真实任务验证两问题批次：选项答案与手写答案整批提交，卡片关闭，历史中两条答案各一次，模型分别确认。
- 536 项单元及原生测试、105 项组件测试通过；新增的 9 项原生输入和进程身份拒绝测试通过。提问相关 55 项测试通过。
- Chromium 与 WebKit 手机交互各 41 项通过，覆盖整批提交、手写回答、拒绝后草稿、计划、权限、队列和 320/390 像素及键盘视口。
- 类型检查、原生编译、生产构建和公开仓库历史扫描通过。

以上真实测试采用本机独立测试任务，没有回答用户业务问题。本次尚未进行 iPhone/Android 真机点击到桌面的端到端验收。
