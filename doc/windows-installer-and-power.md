# Windows 安装版与电源提醒

当前安装包版本：0.4.47。安装与电源策略沿用原实现；新版客户端检查见[桌面兼容说明](./desktop-compatibility.md)。

主界面品牌副标题显示“助手 v0.4.7”，Codex 版本仍在独立状态区域展示。安装包、EXE 文件属性与运行程序的版本统一从 `package.json` 生成，打包拒绝混入旧版程序。`RemoteCompanion.exe --version` 输出助手版本。窗口标题保持不变，重复启动仍拉起已有实例。

0.4.5 及更早助手不包含 Codex 26.908 的工具入口适配，需要覆盖升级至 0.4.7。运行新版安装包，在检测到旧助手时点击“确定”，完成后启动新版助手；不要卸载数据或退出 Codex。升级保留设备 ID、密码、记住授权和订阅。手机刷新网页后，使用“新建并进入任务 → + → 计划模式”，通过输入区计划标签的关闭按钮回到直接执行。

## 服务器连接失败

0.4.7 起，Windows 窗口底部及本机网页显示失败原因和错误编号；恢复连接后自动清除。日志 `%LOCALAPPDATA%\CodexMobile\logs\helper.log` 中的 `server-connection` 事件只记录阶段和固定错误编号，不记录密码、设备密钥、支付密钥或服务器响应正文。

- 设备 ID 为空：尚未成功读取或完成注册、保存凭据。`register/DNS` 表示域名解析失败，`register/TIMEOUT` 表示连接超时，`register/HTTP_429` 表示注册限流，`save/CREDENTIAL_SAVE` 表示本机凭据保存失败。
- `TLS_DATE`：先检查 Windows 日期、时间及自动校时；时间正确时再核对服务器证书。`TLS_CERT`：核对证书链及是否存在 HTTPS 代理拦截，不关闭证书校验。
- `credentials/CREDENTIAL_READ`：核对是否使用原 Windows 用户及其数据目录；不要复制另一台电脑的数据库，也不要自行删除原数据以免失去设备身份。
- 可以在同一台电脑用浏览器访问 `https://remote.chatgptvip.asia/healthz`。正常返回 `{"ok":true}` 只证明浏览器链路可用，不能证明助手进程的证书、代理、防火墙及凭据保存也正常。
- “允许远程连接”只控制手机授权。未勾选时电脑仍应获得设备 ID 并连接服务器；勾选不能修复注册或网络错误。

2026-09-14 已在开发机使用全新隔离数据目录验证公网注册及 WebSocket 连接成功，远控保持关闭且未访问任何桌面任务。其他电脑截图中的具体失败原因尚待该电脑的错误编号确认，此结果不代替异机验收。

历史异机检查曾观察到旧服务器域名的 TLS 握手重置；该入口已随服务器迁移停用。当前 0.4.7 安装包统一使用 `https://remote.chatgptvip.asia`，新服务器证书、443 HTTPS/WSS 和公网健康接口已验证通过。源码仍将 `ECONNRESET`、`UND_ERR_SOCKET` 和 `EPIPE` 归为 `CONNECTION_RESET`，但不再把旧入口的历史现象当作当前故障结论。

## 电源提醒

- 只读取当前 Windows 电源计划，使用 `PowerGetActiveScheme`、`PowerReadACValueIndex`、`PowerReadDCValueIndex` 和 `GetPwrCapabilities`，不解析本地化命令输出，也不修改系统设置。
- 检查实际支持的自动睡眠、已启用的休眠，以及笔记本合盖动作；分别读取接电与电池配置。没有电池或盖子的台式机不会因残留的直流/合盖默认值误报。
- 窗口显示“电源状态”和“电源设置”入口。读取失败显示待检查状态，不宣称安全。关闭显示器不作为自动睡眠证据；现代待机的实际联网还受系统及驱动影响。
- 开启远控且存在风险时通知一次；相同配置不会重复提醒，变更提醒有十分钟冷却。返回助手、供电状态变化、从休眠恢复及每分钟会重新检查。
- “电源设置”只打开 Windows 电源选项，是否调整由用户决定。不保持电脑强制常醒，不禁用休眠，不修改电源计划，也不承诺睡眠、关机或断电时仍可连接。
- 诊断命令：`RemoteCompanion.exe --power-status`，输出 UTF-8 JSON，不需要管理员权限。

## 安装包

- 使用 Inno Setup 生成单文件安装程序，内含完整 Node 运行时、依赖、网页和助手，无需另装 Node.js。
- 当前用户安装，默认目录 `%LOCALAPPDATA%\Programs\CodexMobile`。开始菜单入口自动创建，桌面快捷方式可选；不自动注册开机启动，不自动开启远控。
- 更新时沿用同一安装 ID。检测到正在运行的助手时，安装器点击“确定”会自动退出助手并继续；不关闭 Codex、不停止其任务。旧版助手无法接收退出信号时，安装器只结束远程助手及其 Agent 进程树。
- Windows“应用和功能”提供卸载入口。卸载只移除安装器记录的程序文件，保留 `%LOCALAPPDATA%\CodexMobile` 中的身份、密码、订阅绑定和历史附件，也不删除原 `.codex` 目录。
- 阻止将程序安装进助手数据目录，避免程序与用户数据混放。不要只分发 `RemoteCompanion.exe`，应分发生成的 Setup EXE。
- 目前没有代码签名证书，安装包不得被描述成已签名、已获 Microsoft/OpenAI 认证的商业安装程序。SHA-256 用于核对文件，不替代代码签名。

## 在线更新与本机恢复

0.4.47 起后台只需上传新版 EXE，服务器读取安装器内嵌版本、生成发布序号并校验大小和 SHA-256。管理员填写更新说明后，可以指定设备试发或正式发布；不再上传签名清单 JSON，也不再配置独立发布密钥。客户端通过 HTTPS 获取更新信息，保留下载路径、大小、SHA-256 和版本回放检查；更新信任依赖服务器及管理员权限，SHA-256 不代替发布签名或 Windows 代码签名。

0.4.46 起不再要求服务器提供旧版本恢复包，也不下载旧版安装包。安装前在 `%LOCALAPPDATA%\CodexMobile\updates\program-backups` 备份当前程序，并校验文件清单、版本和 SHA-256；备份失败时不开始安装。

安装失败或新版本机健康检查持续失败时，核验并退出助手及其连接进程，从本机备份恢复程序，再检查恢复版本。服务器暂时离线不触发回退。设备身份、密码、授权、订阅、排队消息和其他用户数据不参与程序恢复；Codex 和正在执行的桌面任务不被停止。恢复无法安全完成时保留备份，避免启动未核验的程序。

旧版更新器中的强制恢复包检查和签名校验无法通过服务器发布新版消除。0.4.46 及更早版本需要先手动运行一次 0.4.47 安装包覆盖升级，无需卸载或删除数据。后续自动更新只下载新版 EXE，不必补传或下载旧版安装包。

## 重复构建

需要 Windows x64、Node 22.13+、.NET Framework 4.8 和 Inno Setup。构建工具只需安装在开发环境，终端用户不需要安装 Inno Setup。

```sh
npm run build
npm run native
npm run package:windows
npm run installer:windows -- --compiler "C:/path/to/Inno Setup/ISCC.exe"
```

也可通过 `INNO_SETUP_COMPILER` 指定编译器，或用 `--package` 指向独立暂存的完整公网包。不要覆盖正在运行的便携版目录，先在暂存目录生成完整包。

默认产物：`release/ChatGPT-Remote-Assistant-Setup-0.4.47.exe` 及同名 `.sha256`。SHA-256 文件只用于用户手动核对，不是后台发布必需文件。打包前通过 `RELAY_URL` 预置 HTTPS 服务器地址，防止把仅连接 localhost 的开发包发给用户。

编译工具来源：Inno Setup 官方 `jrsoftware/issrc` 的 `is-7_1_0` 发布，文件 `innosetup-7.1.0-x64.exe`，SHA-256 为 `0362a383ed217d4c4239b5933866dd96d3eb2102737da92f80f6057a4b40df2f`。官方随附许可允许商业使用；保留上游归属，不把安装引擎冒称为本项目原创。

## 原安装流程验证

- 电源判断覆盖自动睡眠、已禁用休眠、电池、合盖睡眠/关机、未知设置及现代待机说明；测试不改变真实电脑的电源配置。
- 原生窗口检查八种布局，包括风险与读取失败状态。
- 安装回归脚本为 `tests/installer-smoke.ts`，需先退出助手，且当前 Windows 用户不存在该安装器的既有安装。它在工作区临时目录验证安装、覆盖升级、卸载、用户数据库保留和未登记文件保留，不会启动真实任务。
- 111 项自动测试通过；其中电源测试校验 15 项判断，原生布局覆盖八种状态，风险和读取失败样式均已检查。
- 实际安装程序的首次安装、相同版本覆盖升级和卸载均通过；设备数据 SQLite 的 SHA-256 保持不变，程序目录中未登记的测试文件保留。验收日志位于 `.runtime/installer-smoke-*`，避免与卸载器尚未释放的日志句柄争抢。
- 助手运行中安装程序会拒绝覆盖，没有写入目标程序文件，也不会强杀 Codex 或其他 Node 进程。
- 已在本机完成标准目录安装，开始菜单和桌面快捷方式存在，新助手已启动。只卸载了隔离的验收安装，不卸载用户原数据。
- 安装后的助手已通过公网重新配对检查：服务器在线、远控启用状态保留、设备 ID 与原自定义密码不变。测试配对已注销，没有发送真实任务消息。
- 安装后的只读电源诊断为当前高性能方案、自动睡眠“从不”、无配置风险，与安装前 `powercfg` 核对一致；没有为了测试而把真实电脑设为睡眠。
- 本轮没有修改服务器的配置、收费开关或其他业务。官方编译器只作为开发构建依赖，未采购云资源或签名证书。
