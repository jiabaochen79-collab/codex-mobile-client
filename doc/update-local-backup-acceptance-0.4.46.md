# 0.4.46 在线更新本机备份验收

日期：2026-10-08。本次只修改公开客户端，服务器和协议仓库没有改动，没有生产服务器网络请求或部署。

## 交付行为

- 检查、下载和安装只依赖新版签名安装包，不要求服务器提供当前版本或其他旧版安装包。旧版元数据不参与下载或校验。
- 独立更新进程在安装前备份当前程序，校验文件清单、版本和 SHA-256。磁盘空间或备份校验失败时不开始安装。
- 安装失败或持续的本机健康检查失败时，只退出身份核验通过的助手及其连接进程，再从本机程序备份恢复。服务器离线不作为回退原因。
- 恢复前先验证备份和暂存副本，支持失败安装删除整个程序目录的情况。身份、密码、授权、订阅及其他用户数据不回滚。
- 无法核验进程、安装器仍运行或备份损坏时，保留备份并报告失败，不启动未核验的程序。
- 旧更新器中的恢复包检查仍然存在，需手动覆盖安装一次本版本；不能通过服务端发布新版消除旧客户端的本地限制。
- 此版本没有实现助手主程序自身的独立守护。
