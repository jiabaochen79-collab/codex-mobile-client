# 0.4.51 任务结束后提问丢失修复

日期：2026-10-11。

## 根因与行为

本机 Codex 应用版本为 `26.1007.21434`。对用户报告会话进行只读 IPC 检查，确认桌面为 `idle`、提问所在轮次为 `completed`、旧式 `requests` 为空，但 `agentMessage.questions` 仍包含未回答问题。0.4.50 的提取逻辑在桌面空闲时直接返回空列表，并只读取 `inProgress` 轮次，因而手机丢失问题。

0.4.51 独立处理轮次结束与提问回答状态：最新轮次未回答的问题在完成后继续显示，读取不受消息分页限制。桌面接受回答或跳过后清除对应问题；待处理、被拒绝或被中断的回复不会清除问题。新轮次开始后不再展示旧轮次的问题。

运行中的回答继续使用原生 steering；任务结束后的回答使用原生 start-turn，保留问题标识、幂等消息标识及继承任务设置。接口不兼容时拒绝提交，原生提交失败后保留问题供用户重试。

未修改手机页面、服务器实现或通信契约。
