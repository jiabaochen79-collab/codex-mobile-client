# Codex Mobile · ChatGPT Remote Assistant

**Keep your computer working. Pick up from your phone.**

English | [简体中文](README.zh-CN.md)

**[Download for Windows · GitHub](https://github.com/jiabaochen79-collab/codex-mobile-client/releases/latest)** · **[Gitee downloads](https://gitee.com/gitee-is-future/codex-mobile-client/releases)** · [Open mobile website](https://remote.chatgptvip.asia/)

Continue your computer's Codex conversations from your phone: check progress, send follow-ups, and answer questions or approvals. Keep your projects where they are, without staying at your desk.

## Features

| Feature | What you can do |
| --- | --- |
| Continue conversations | Follow progress and results, add requests, or steer ongoing work |
| Queue on the computer | Close the phone page after your queued request is confirmed saved |
| Plans and goals | Review a plan before execution, or work toward a defined goal |
| Questions and approvals | Choose an option or write your own answer; set permissions per task |
| Photos and files | Take photos, upload files, and process supported HEIC images |
| Multiple computers and terminals | Switch paired computers; authorized terminals can act without taking control |
| Task reminders | Get alerts for completion, problems, or decisions, then open the relevant task |
| Updates and recovery | Download updates in the background, confirm installation, and recover supported failures |

## Start in Three Steps

1. **Install the Windows assistant.** Open and sign in to Codex, check that it is ready, and enable remote connections.
2. **Copy the connection information to your phone.** Open the mobile website and enter the device ID and password.
3. **Choose a conversation and continue.** Work runs on your computer; your phone can use a different network.

Requires Windows 10 (19041+) or 11, x64, and a working Codex desktop installation. Keep your computer online and awake, with Codex and the assistant running.

For iPhone notifications, add the site to the home screen and enable reminders inside that Web App. Android Chrome can request notification permission directly.

## About

The client is open source under [Apache-2.0](LICENSE). The relay is operated separately; check the in-app subscription page for trials and service access. Server code is not included.

This is an unofficial project, not affiliated with OpenAI. It does not include a ChatGPT subscription or model credits. Connections use HTTPS; the relay can process forwarded content, so this is not end-to-end encryption. Windows installers are currently unsigned; release pages include SHA-256 checksums.
