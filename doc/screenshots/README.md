# Documentation Screenshots

These PNGs were captured from the real Vue components in client version 0.4.57,
using an isolated local Vite server and Playwright with fabricated API/WebSocket
responses. No production service, account, conversation, or device was used.
The interface was not replaced with a mockup and the images were not retouched.

| `mobile-chat.png` | Completed conversation and collapsed execution | 390 x 844, scale 2 |
| `mobile-computers.png` | Paired computer switcher | 390 x 844, scale 2 |
| `mobile-notifications.png` | Per-computer reminder settings and history | 390 x 844, scale 2 |

`123456789`, `987654321`, the masked `DEMO2026` password, computer names, tasks,
model selection, entitlement, notification times, and results are demonstration
data. The relay URL is the public service entry point, not a secret. Screenshots
illustrate the interface and do not constitute a real-device or delivery test.

When refreshing these images, use synthetic data again, inspect each image for
